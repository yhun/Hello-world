Playwright คือเครื่องมือที่ให้ Python “ควบคุมเว็บเบราว์เซอร์” ได้เหมือนคนจริง — คลิก พิมพ์ กรอกฟอร์ม ดาวน์โหลดไฟล์ อ่านข้อมูล ถ่ายภาพหน้าจอ — แต่เร็วกว่า ไม่เหนื่อย และทำได้ตลอด 24 ชั่วโมง

และเมื่อจับคู่กับ AI คุณไม่จำเป็นต้องเขียนโค้ดเองทั้งหมด — แค่ อธิบายงานเป็นภาษาคน แล้วให้ AI เขียน script ให้ หรือให้ script เรียก AI มาช่วยคิด/สรุป/จัดหมวดข้อมูลระหว่างทาง

ติดตั้ง (ทำครั้งเดียว)

pip install playwright
playwright install chromium

Script แรก: เปิดเว็บแล้วถ่ายภาพหน้าจอ

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)  # False = เห็นหน้าจอขณะทำงาน
    page = browser.new_page()
    page.goto("https://example.com")
    print("หัวข้อหน้าเว็บ:", page.title())
    page.screenshot(path="example.png", full_page=True)
    browser.close()

คำสั่งที่ใช้บ่อย (Cheat Sheet)

อยากทำคำสั่ง
ไปที่หน้าเว็บpage.goto("https://...")
คลิกปุ่มจากข้อความpage.get_by_role("button", name="ค้นหา").click()
พิมพ์ในช่องpage.get_by_label("อีเมล").fill("me@co.com")
เลือก dropdownpage.select_option("#province", "กรุงเทพ")
อ่านข้อความpage.locator(".price").inner_text()
อ่านทุกแถวของตารางpage.locator("table tr").all_inner_texts()
รอให้ element ปรากฏpage.wait_for_selector("#result")
ดาวน์โหลดไฟล์with page.expect_download() as d: ...
อัปโหลดไฟล์page.set_input_files("input[type=file]", "a.pdf")
บันทึกเป็น PDFpage.pdf(path="report.pdf")
เก็บ Login ไว้ใช้ซ้ำcontext.storage_state(path="auth.json")

Use Cases: Python + Playwright ทำอะไรได้บ้าง

คลิกที่การ์ดเพื่อดูตัวอย่างโค้ด และ Prompt สำเร็จรูป ที่ก๊อปไปให้ AI เขียน script ให้ได้ทันที

ไอเดีย Automate ตามแผนก

เลือกแผนกของคุณ เพื่อดูงานที่น่าจะ automate ได้

AI + Playwright: 3 รูปแบบการใช้งาน

รูปแบบ 1

🧑‍💻 AI เขียน Script ให้

คุณอธิบายงาน → AI (เช่น Claude) เขียนโค้ด Python + Playwright → คุณรันเอง

เหมาะกับ: งานที่ขั้นตอนชัดเจน ทำซ้ำเหมือนเดิมทุกครั้ง · ถูกที่สุด เพราะเรียก AI แค่ตอนเขียน

รูปแบบ 2

🔗 Script เรียก AI ระหว่างทาง

Playwright ดึงข้อมูล → ส่งให้ AI สรุป/จัดหมวด/แปล/ตรวจ → บันทึกผล

เหมาะกับ: ข้อมูลเป็นข้อความที่ต้อง “คิด” เช่น รีวิวลูกค้า อีเมล ข่าว สัญญา

รูปแบบ 3

🕹️ AI Agent ควบคุม Browser เอง

สั่งเป้าหมาย เช่น “หาราคาตั๋วถูกสุดวันศุกร์นี้” → AI ตัดสินใจเองว่าจะคลิกอะไร (ผ่าน Playwright MCP / Claude in Chrome)

เหมาะกับ: งานที่หน้าเว็บเปลี่ยนบ่อย หรือขั้นตอนไม่แน่นอน · ช้าและแพงกว่า ต้องมีคนตรวจ

🧭 เลือก Model ให้เหมาะกับงาน (Model Routing)

ไม่จำเป็นต้องใช้ model ที่แพงที่สุดกับทุกงาน — ให้ Script เลือก model ตามความยากของงาน ช่วยประหยัดได้มาก

ประเภทงานตัวอย่างModel ที่แนะนำ
🟢 ง่าย / ปริมาณมากจัดหมวดรีวิว บวก/ลบ, ดึงเบอร์โทรจากข้อความ, แปลสั้น ๆclaude-haiku-5-5 — เร็ว ถูกมาก
🟡 งานทั่วไปสรุปรายงาน, เขียนอีเมลตอบลูกค้า, เปรียบเทียบข้อมูลclaude-sonnet-5-5 — สมดุลเร็ว/เก่ง
🔴 ซับซ้อน / ต้องแม่นวิเคราะห์สัญญา, เขียน Script automate ทั้งระบบ, วางแผนหลายขั้นตอนclaude-opus-5-5 — เก่งที่สุดในราคาสมเหตุผล

ลองเลย: ให้ระบบเลือก Model ให้

ตัวอย่างโค้ด: Playwright ดึงข้อมูล → Script เลือก Model ตามงาน → AI ประมวลผล

❓ คำถามที่พบบ่อย

      
ต้องเขียนโปรแกรมเป็นไหม?
ไม่จำเป็นต้องเก่ง — ใช้ playwright codegen อัดการคลิก + ให้ AI ช่วยเขียน/แก้โค้ด แค่ต้องติดตั้ง Python และรันคำสั่งได้

      
Playwright ต่างจาก Selenium ยังไง?
Playwright ใหม่กว่า รอ element ให้อัตโนมัติ (error น้อยกว่า) รองรับ Chrome/Edge/Firefox/Safari มี codegen และ trace viewer ในตัว

      
ใช้กับโปรแกรม Desktop (เช่น SAP GUI, Excel) ได้ไหม?
Playwright ใช้กับ “เว็บ” เท่านั้น สำหรับ Excel ใช้ openpyxl/pandas ส่วนโปรแกรม Desktop ใช้ pywinauto หรือเครื่องมือ RPA อื่น ๆ — แต่ระบบสมัยใหม่หลายตัวมีเวอร์ชันเว็บซึ่ง Playwright ทำได้

      
ถ้าหน้าเว็บเปลี่ยน script จะพังไหม?
อาจพังได้ ควรใช้ locator ที่อิงข้อความ/role (get_by_role, get_by_label) ซึ่งทนกว่าการอิง CSS class และเมื่อพังให้ส่ง error + HTML ให้ AI ช่วยแก้

      
ใช้ AI เรียกเว็บแทนเขียน script ไปเลยดีกว่าไหม?
ถ้างานทำซ้ำเหมือนเดิมทุกวัน “script” ถูกกว่า เร็วกว่า และแน่นอนกว่า ใช้ AI agent เมื่อขั้นตอนไม่แน่นอนหรือทำนาน ๆ ครั้ง
